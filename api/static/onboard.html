GAB Onboarding

One page: load accounts (with passwords), add the OAuth client, authorize each account, then push the first environment. Consumer Google accounts only. Reset logins →
1 · Accounts (CSV: email, persona, password, mode)
Each line: email, persona, password, mode (any column order; persona & mode auto-detected). mode is optional — one of upload (first seed), reconcile (reset to baseline), reseed (wipe + seed), delta (finish/retry), clean (empty-universe: wipe the account to blank, seed nothing — leave persona empty). Blank = auto. Password stays in your browser, never sent to the server.

Authorize opens Google's consent in a new tab — sign in (copy the password from the row), click Allow; the row flips to authorized here. "Authorize all" walks the accounts one after another, opening each consent tab in turn. Upload seeds the account's persona (writes reset_sessions + manifest); Bulk upload seeds every authorized account. Retry skipped runs a delta for missing/failed items.
